# Caniogan Re:Quest

Community requests and barangay services for Caniogan, Malolos, Bulacan.

The application is in **caniogan-reQuest/**. Follow its [setup and team workflow](caniogan-reQuest/README.md).

```powershell
git clone https://github.com/lequita1/caniogan-re-quest.git
cd caniogan-re-quest/caniogan-reQuest
```

Install dependencies and configure your local environment using the linked guide. Start each task on a branch created from the latest `main`; merge through a reviewed pull request.
